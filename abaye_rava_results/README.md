## שחזור ובדיקות

הריצו מתיקיית הפרויקט:

```sh
python -X utf8 abaye_rava_search.py
python -X utf8 abaye_rava_review_views.py
python -X utf8 build_abaye_rava_report.py
python -X utf8 verify_abaye_rava_sources.py
node abaye_rava_results/verify_report.cjs
```

הסריקה מקבלת גם `--corpus-root`. החלטות הקריאה תקפות ל־snapshot הנוכחי; שינוי מקור או תבנית מחייב התאמת ההחלטות לפי המפתחות, ולא שימוש עיוור במספרי שורות. הבונה קורא רק את תבנית ה־HTML של הדוח הקודם ואינו מריץ או משנה את מחקר רב ושמואל.

בדיקת המקורות בודקת התאמת ציטוטים, כתובות וחתימות קבצים. בדיקת Node בודקת את ממשק הדוח בלבד. אף אחת מהן אינה מאמתת את הסיווג המחקרי או מבטיחה מיצוי.
