# מחלוקות רבה ורב יוסף — מפתח מקורות

נסרקו 76 מסכתות: 37 בבבלי ו־39 בירושלמי, ובהן 94,045 קטעים שאינם ריקים. המפתח כולל **101 מראי מקום ב־27 מסכתות בבבלי**. אלו הופעות במקור, ולא מספר סוגיות ייחודיות. נכללו מחלוקות בדין, תירוצים ודרשות חלופיים, חילופי מסירה, השגות והמשכי דיון. מקרה אחד סומן כהשגה שהתיישבה (יבמות מה ע״א). לא נבחרה רשומה בירושלמי; אין בכך הוכחת העדר.

## קבצים לשימוש

- `מחלוקות_רבה_ורב_יוסף.html`: להוריד ולפתוח בדפדפן; חיפוש בעברית וסינון לפי מסכת וסיווג, ללא חיבור לרשת. GitHub אינו מפעיל HTML בתצוגת הקובץ.
- `מחלוקות_רבה_ורב_יוסף.txt`: ציטוטים והקשר להעתקה, עם הפרדה מהערות המחקר.
- `rabbah_yosef_index.json`: נקודת כניסה לסוכן אחר; כולל כתובות, ציטוטים, הערות, נתיבי המקור, אינדקסים ו־SHA-256.
- `candidates.json`, `broad_candidates.json`: 207 מועמדי תבניות ו־477 חלונות סמיכות חופפים; אינם רשימת מחלוקות מאומתות.
- `review_decisions.json`, `supplemental_decisions.json`: החלטות בחירה, מזהים ונימוקים. נבחרו 102 מועמדי תבניות ו־12 חלונות נוספים, שאוחדו לפי כתובת פתיחת הקטע.
- `coverage.json`: פירוט כל המסכתות, גם אלו ללא רשומה שנבחרה.
- `recall_audit.json`: בדיקת החמצות מוגבלת בתבנית נפרדת.

## שיטה ומגבלות

המקור הוא גוף התלמוד בקובצי `Hebrew/merged.json` ב־`F:/Sefaria-Export-master/json/Talmud`. לא נכללו פירושים בסריקה הזאת. הכתובות נגזרות ממערכי המקור, ולא ממאגר מנורמל שבו נמצא בעבר היסט דף. ניקוד, תגיות וריווח נורמלו; קובצי המקור לא שונו.

החיפוש מפריד רבה מרבא ומאפשר גם רבה בר נחמני, תחיליות ופעלי אמירה ברבים. חלון סמיכות הוא עד 1,400 תווים או בתוך אותו קטע. סמיכות שמות אינה הוכחה למחלוקת. גם לאחר סינון שמות אחרים נשארות בפלט הגולמי מילים כגון מרבה וגברא רבה שאינן שם החכם.

בוצעה קריאה ראשונית, חלקה בתצוגות מקוצרות, של מועמדי התבניות ושל חלונות הסמיכות שלא יוצגו כבר בכתובת פתיחה שנבחרה. 47 מועמדים סווגו כאמירה משותפת ו־58 נשארו לבדיקה. חלונות סמיכות שלא נבחרו אינם בגדר שלילה מאומתת. **לא נקראה כל סוגיה מתחילתה עד סופה, ואין לטעון לשלמות הרשימה.** השגות עקיפות, כינויים, מרחק בין אמירות וחילופי נוסח עלולים לגרום להחמצות.

נשמרו הערות מיוחדות על ואיכא דאפיך להו בגיטין סז ע״א, חד אמר בבבא קמא נא ע״ב, ורבה/רבא בסוטה כא ע״א ובבבא בתרא לב ע״ב. בסנהדרין צח ע״ב רבה מופיע בסוגריים מרובעים. אין להשלים ייחוס לפי סדר השמות. סימוני חזרה ויישוב אוטומטיים עלולים להתייחס לדיון סמוך.

בדיקת החמצות נפרדת מצאה 23 קטעים שבהם שתי התבניות המפורשות רבה אמר/אומר ורב יוסף אמר/אומר: 22 במפתח, והאחרון (עירובין פח ע״א:9) מביא אותו דין משני מורים שונים. זו בדיקה צרה בלבד.

## שחזור ובדיקות

מהתיקייה הראשית, עם Python 3 ו־Node:

```text
python -X utf8 rabbah_yosef_search.py
python -X utf8 build_rabbah_yosef_report.py
python -X utf8 audit_rabbah_yosef_recall.py
python -X utf8 verify_rabbah_yosef_sources.py
node rabbah_yosef_results/verify_report.cjs
node rav_shmuel_results/verify_report.cjs
```

הבונה מפעיל את `rabbah_yosef_review.py`. ניתן למסור לסורק `--corpus-root` עם נתיב אחר לאותו יצוא. לבנייה ולבדיקת המקורות עדיין נדרש המאגר המקומי המקורי. הבנייה משתמשת גם בפונקציות טעינת המקור של Abaye–Rava ובתבנית HTML של Rav–Shmuel, ללא שינוי בתוצריהם.

מזהי המועמדים קפואים; נבדק גם גיבוב הקובץ לפני החלת ההחלטות. אם משנים את הסורק, יש למפות מחדש את ההחלטות לפי המפתחות היציבים. מאמת המקורות קורא את מערכי JSON ישירות ובודק את 101 ההפניות ואת 626 ציטוטי ההקשר. בדיקות הממשק בודקות חיפוש, עימוד וסינון בלבד. הן אינן הוכחה לנכונות הסיווג או לשלמות המחקר.
