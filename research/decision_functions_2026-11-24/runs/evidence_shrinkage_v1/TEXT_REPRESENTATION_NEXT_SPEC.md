# Proposal only: representation and base-model transport

No encoder is chosen, downloaded or run here. This specification does not authorize a new numerical, text or human experiment.

The current estimand is new people/new grouped questions with16 fixed, well-covered observations. A later representation study should retain B1 (four training-prior pseudo-observations), B2 (population/shared predictor), B3 (personal offset), M1 and the fixed-mixture control, with equal histories and query inputs. Freeze representation normalization, shared/personal penalties, label meanings, outcome-blind group splits, ties, practical effect thresholds and accuracy tradeoffs before fitting. Freeze a matched numerical control and compare representations on identical episodes; seeds and histories are not independent people.

The count-conditioned identity assumes correct known shared logits g, common fixed three-class meanings, independent categorical responses conditional on personal parameters, support selection independent of target responses, and a prior/basis trained without target outcomes. A constant class shift in g is absorbed by the personal offset. Arbitrary fixed text features do not themselves invalidate this identity, but a question-dependent error in an estimated population predictor can. A learned or misspecified g therefore needs a separate null-validity argument and calibration/misspecification experiment. Do not transport the .009 bound by assertion.

A later study should distinguish representation power with oracle g from estimation of g, preserving common labels and pair/group provenance. If evidence shrinkage fails recovery, first propose a separately frozen power/representation diagnosis; if it qualifies, propose a bounded limited-history representation study with independent data and null-validity controls. Neither outcome licenses tuning E/F/G/H or a human test here. History controls should include matched others under declared matching and information budgets; report probability loss and accuracy even when they disagree. Use paired person/group uncertainty, disclose retraining uncertainty, and define a scientifically worthwhile improvement separately from numerical tolerance.
