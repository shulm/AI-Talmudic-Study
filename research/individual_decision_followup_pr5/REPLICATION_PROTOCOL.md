# Prospective collection and replication specification v1

Status: specification only. No cohort admitted, no collection launched, no independent confirmation run. This is a proposed position-controlled conceptual replication of Kirby-to-Holt–Laury transfer, not an extension of the exposed SRO test. Actual recruitment requires separate user authorization and applicable institutional/ethics and consent approvals. No permission or human review is assumed.

## Admission and participant contract

Recruit consenting adults able to understand the fixed task instructions, once per person, with no participation in the original SRO508 or any new development/confirmation role twice. Use a consented privacy-preserving recruitment registry to enforce uniqueness and exclude known prior study participants; quarantine unresolved identity matches before randomization. Do not publish identifiers or participant-level responses. A custodian must certify cohort provenance, permitted analysis/use, exclusions and distinctness before unblinding. Pseudonym changes or claims of a new release do not suffice. Unknown independence blocks confirmation.

Store a stable pseudonymous person/session/trial key; consent/release version; task/instruction version; trial ordinal; semantic alternative IDs; full amounts, delays and probabilities; actual left/right positions, key mapping, layout assignment, selected semantic ID and key, timestamp, response status and payment rule. Preserve immutable raw events plus a hashed canonical table; audit key-to-choice reconstruction against runtime code and rendering tests. No imputation of missing choices. Exclude only withdrawal, duplicate identity, technical failure or incomplete required18 choices, determined by completeness metadata before outcomes. Do not exclude inconsistent or nonmonotone preferences. Retain an exclusion ledger; replacements follow the next randomized slot before any confirmation scoring. No outcome-dependent stopping.

Use the eight fixed source probes below, in this order, with immediate amount, later amount and delay in days: (11,30,7), (40,55,62), (33,80,14), (54,80,30), (34,50,30), (14,25,19), (27,50,21), (54,55,117). Target safe lottery pays100/80; risky pays190/5, common high-outcome probabilities .1,.2,...,1, in that order. Use a single declared local currency and hypothetical-choice instructions for all participants, with a fixed participation payment unrelated to choices. These choices deliberately change incentive context if the archive used another payment rule; the inference is conditional on this protocol, not an exact behavioral reproduction. Final instruction text, translation and comprehension checks must be versioned before enrollment; this operational approval gate remains open. No trial feedback, adaptive items or outcome realization before completion. Source precedes target; no task-order generalization claim.

## One prospective model specification

Implement a rank2 semantic profile using the exact eight-dimensional alternative-difference feature construction/scaling in PR5 `data_pipeline.py` at delivery6ca2ded (semantic risky-minus-safe and later-minus-immediate, independent of screen side). Use frozen code-derived scaling; do not fit feature scaling to confirmation. The source and target tasks remain one family each. This is a prospective model definition, not a retroactive redefinition of PR5's dim8 result.

Use PR5 ProfileModel fitting/inference algorithm with these declared changes: dim2, reg.1; replace penalty `reg*mean(B**2)/2` with `reg*sum(B**2)/(2*F)`, F=8, so Frobenius scaling does not depend on dimension; zero-budget prediction and training use the same integrated N(0,I) prior as positive-budget posterior predictions. All other constants remain: population ridge.01,100 Adam epochs, step.04, initial B Normal(0,.15), five damped Newton steps with damping.8 during training, gradient clip10, float64, one CPU thread; converged MAP at inference with original tolerance, Laplace covariance and20-node Gauss–Hermite integral. Train equally over budgets0/2/4/8 and people, seeds17/29/43, averaging probabilities over seeds before computing any loss. No architecture/dimension/penalty search, temperature fit or confirmatory refit. Failures stop the freeze; do not silently drop a seed. Source inference uses exactly the charged prefix, never target answers or a target-fitted state. The change requires executable tests and independent review before deployment; no prospective model is fitted in this follow-up.

Source-blind candidates: training-only Beta(.5,.5) frequencies for each target item within its target layout; the same frozen profile integrated Normal prior; its uniform empirical mixture over all200 development participants' source-only posteriors at the charged budget; and the training-only PR5 population predictor. Select lowest pooled development NLL at8, ties within1e-12 in listed order. For development empirical comparisons use two100-person folds stratified across the four layout pairs; opposite fold is the disjoint bank, with50 donors matching recipient source layout. Within each of the four50-person layout strata, sort SHA256(`20261128|replication_fold|person`) and alternate people into the two folds (25 per stratum per fold). No recipient answers choose the source-blind mixture. For confirmation use the full development bank, with100 matching-source-layout people for each recipient. Bank size change is declared; probabilities are conditional on fixed banks. For empirical prior/bank predictions, use target semantic scenarios only; item frequencies alone use target layout metadata. No separate varying-item context predictor is needed for these ten fixed items.

Five single donors are selected without replacement from matching source-layout bank using diagnostic SHA256(`20261124|diagnostic_donor|assignment|person`) modulo sorted bank and duplicate advancement. Match source probe order, budget, source layout and instruction version; never responses or target outcomes. Target alternatives are rendered according to the recipient's target metadata, never the donor's target answers. Freeze bank membership, assignments and inferred source states before confirmation scoring. Average seeds within each single donor prediction, score each donor, then average losses. Separately score the mean of five donor probability vectors. Keep donor-mixture and a training-only PR5 SummaryModel(reg1,population_reg.01) as supporting controls; no summary hyperparameter search.

Position-only personal control: Beta(.5,.5) posterior probability of choosing right from k source choices, (right_count+.5)/(k+1), projected to recipient target risky-side mapping. At zero it is.5. Its complement supplies the other alternative. It sees no money, delay, probabilities or target responses. Report position-control-minus-own loss and each of four layout strata descriptively. A positive primary pair alone supports person-specific prediction conditional on tasks, not pure monetary preferences. A semantic-transfer interpretation additionally requires own to beat this control (paired95% lower bound of control-minus-own >0), with no claim of multiplicity-adjusted trait identification. Opposite-layout failure or inconsistent strata must be discussed, not hidden by pooling.
