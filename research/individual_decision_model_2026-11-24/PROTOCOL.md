## Models and development selection

Retain R_s(q,c,a)=R_0(q,c,a)+z_sᵀφ(q,c,a), probabilities softmax over available alternatives, z_s~Normal(0,I). In the binary implementation, feature vectors are alternative-1 minus alternative-0. Shared φ is a small linear basis on eight fixed monetary scenario features. Train shared parameters on source-support/target episodes. Infer only z from the new person's revealed source responses. MAP and Laplace covariance are approximate; integrate predictive uncertainty using the documented approximation in models.py. Do not fit personal temperature. No encoder or external model API.

Compare population/context logistic, source-summary mapping, common-probe retrieval, individual profile and matched other-person profile. All receive identical source probes and budget. Summary uses only revealed binary semantic responses; retrieval compares only matching revealed probe responses and uses training target responses as its reference bank. Its reference people differ from the new person. Population and source-summary regularization grid {0.1,1}; profile dimension {2,4,8}, regularization {0.1,1}. Select each by validation participant-mean target NLL at budget eight; ties use smaller dimension then larger regularization. Exact optimization settings and training episode budgets are frozen in models.py and configuration manifest before fitting. Meaningful profile stability seeds 17,29,43; use the three-seed mean probabilities for configuration selection and final prediction. No seed is an independent person. Deterministic comparators are not redundantly refit.

At budget zero use the population fallback for every model. Shared fitting uses training people only, including training target labels. Development validation labels select configurations but never update fitted parameters; do not retrain on train+validation. Fit no test-person coefficients with target labels. No post-test calibration. Calibration assessment uses ten fixed probability bins, reports frequency, mean predicted probability and observed frequency; calibration itself is not fitted.

Matched donors come from the frozen **validation** source-only reference pool, which is disjoint from test people. Everyone has the same source task, condition, probes and complete coverage. For each test person, five donor assignments are chosen by SHA256(20261124|donor|assignment|person), modulo the sorted pool size, resolving duplicates by moving to the next pool index. Choices and target labels do not enter matching. Infer donor z afresh from exactly k source choices; never reuse a target-fitted personal vector. Save donor assignments locally before final scoring. Average five donor predictive distributions, then score that mixture; also retain assignment-level probabilities. Donor identities do not change during bootstrap.

## Estimands and decision

Co-primary at k=8: Δpersonal=NLL(population)−NLL(own profile); Δspecific=NLL(matched-donor mixture)−NLL(own profile). Also report NLL(summary)−NLL(profile), retrieval comparisons and all budgets. Compute negative log probability of the complete observed alternative in natural units, not token NLL. Average trials within task family, families within participant, then participants equally. Here there is one target family with ten complete trials. Report binary full-vector Brier (sum of two squared class errors), accuracy, calibration, eligible/actual counts and exclusions.

Two-sided 95% paired participant-cluster percentile bootstrap, 2,000 draws, NumPy default_rng seed 20261124. Keep each person's episodes together and development donor pool fixed. Intervals condition on fitted models, donor pool and these task families; no claim of uncertainty over general task domains. Report the same bootstrap index draws for paired comparisons. No multiplicity-adjusted secondary claims. Threshold for each co-primary contrast is **zero**, a provisional signal test; no defensible application utility threshold exists. Do not claim demonstrated practical benefit.

Outcome rule: positive individual signal only if both lower endpoints exceed zero. If this holds but profile does not establish improvement over summary (summary-minus-profile lower endpoint ≤0), classify **simpler model sufficient**, qualified as no demonstrated added value of profile complexity, not statistical equivalence. If either co-primary upper endpoint ≤0, **extension not supported**. Otherwise **inconclusive**.
