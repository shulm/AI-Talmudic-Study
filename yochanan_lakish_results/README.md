# רבי יוחנן וריש לקיש — מפתח מקורות

563 מראי מקום: 338 בבבלי ו־225 בירושלמי, ב־71 מסכתות. נסרקו כל 76 המסכתות שבמאגר המקומי — 94,045 קטעים. זהו מספר מופעים, לא מספר מחלוקות ייחודיות.

פתחו את קובץ HTML בדפדפן לחיפוש עברי, סינון לפי תלמוד ומסכת, הקשר מלא והדפסה. GitHub מציג את קוד הקובץ ואינו מפעיל אותו; יש להורידו. TXT מתאים להעתקה, ו־`yochanan_lakish_index.json` לעבודה עם סוכן אחר.

## דרגת הבדיקה

קריאה ראשונית של ציטוטים, חלקם בתצוגות מקוצרות; לא בדיקה של כל הסוגיות מתחילתן ועד סופן. נכללו הבדלי פירוש, ראיות ותירוצים, נוסף על מחלוקות מעשיות. סמיכות שמות אינה מוכיחה מחלוקת. אין לייחס חד אמר לפי סדר השמות; בירושלמי לעיתים ההמשך משנה ייחוס מוצע. הערות על חזרה/חילוף/יישוב הן בחלקן אוטומטיות ודורשות בדיקה.

1,409 מועמדי תבניות: 722 נבחרו, 134 צימודים הוצאו, 553 טעונים בדיקה נוספת. נוספו 17 קטעי משא ומתן מתוך 2,109 חלונות סמיכות, ושתי אמירות בלשון רבים שבהן רבי יוחנן וריש לקיש בקבוצות חולקות (עירובין ח ע״ב, מנחות נד ע״א; מספרים 562–563). לאחר איחוד לפי כתובת התקבלו 563 רשומות. החלונות חופפים ואינם עוד 2,109 מחלוקות. המועמדים שלא נבחרו אינם קביעה של העדר מחלוקת; נותר סיכון להחמצות.

## מקורות ושמות

גוף הבבלי והירושלמי בקובצי `merged.json` של Sefaria, ללא פירושים. חיפוש רבי יוחנן מול רבי שמעון בן לקיש, ריש לקיש, בר לקיש, רשב״ל, ר״ל, ר״ש בן לקיש וכינויי ר׳. ר״ל יכול להתפרש אחרת ולכן מסומן כעמימות. הסורק אינו מזהה פעלים בלשון רבים (אמרו/אמרי), ואינו מסנן את רבי יוחנן הסנדלר (מופיע רק בחלונות סמיכות שלא נבחרו). טווח צימוד: עד 1,400 תווים; ניסוחים עקיפים ומרוחקים עלולים להחמיץ.

הציטוטים שומרים את נוסח המאגר לאחר הסרת תגיות וניקוד ונרמול רווחים/גרשיים. לא בוצע תיקון תוכן. לכל רשומה מקור, אינדקס מערך, SHA-256 וקישור. בבבלי הכתובת נגזרת ישירות ממערך הדפים המקורי; בירושלמי היא פרק:הלכה:קטע, לא עימוד דפוס וילנה. קובצי המקור לא שונו.

## שחזור ובדיקות

הריצו מתיקיית הפרויקט (Python ו־Node, ספריות מובנות בלבד):

```sh
python -X utf8 yochanan_lakish_search.py
python -X utf8 build_yochanan_lakish_report.py
python -X utf8 verify_yochanan_lakish_sources.py
node yochanan_lakish_results/verify_report.cjs
node rav_shmuel_results/verify_report.cjs
```

אפשר להעביר לסורק `--corpus-root` המצביע על תיקיית `json/Talmud`. החלטות הסינון מתייחסות לתמונת המקור הנוכחית: אין לשנות מספור בלי מיפוי מחדש לפי המפתחות. `review_decisions.json` ו־`supplemental_decisions.json` שומרים את מסלול ההחלטות; `coverage.json` שומר גם מסכתות ללא תוצאות.

בדיקת המקורות קוראת ישירות את מערכי המקור ובודקת ציטוטים, כתובות וחתימות. בדיקת הממשק בודקת חיפוש וסינון בלבד. שתיהן אינן מוכיחות שהסוגיה היא מחלוקת או שהמפתח ממצה.
